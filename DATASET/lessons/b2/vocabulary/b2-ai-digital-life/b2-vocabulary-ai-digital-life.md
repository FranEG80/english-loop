# Resumen

La inteligencia artificial aparece en el trabajo, la educación, los servicios públicos y las aplicaciones móviles. Esta lección permite describir sistemas y resultados sin confundir términos técnicos: un algorithm procesa instrucciones, un dataset reúne datos y machine learning detecta patrones. También se practican privacy, bias, encryption, digital footprint y data breach, junto con verbos para instalar, actualizar y solucionar herramientas.

# Objetivos

- Explicar qué hacen un algoritmo, un modelo y una interfaz.
- Hablar de automatización, reconocimiento y asistentes conversacionales.
- Valorar sesgos, privacidad, seguridad y huella digital.
- Resolver problemas de compatibilidad, actualizaciones y configuración.

# Léxico y combinaciones

- train a model / process data / detect a pattern
- automate a task / generate a response / recognise an image
- protect privacy / encrypt a file / obtain consent
- update software / install a patch / troubleshoot a connection
- a biased dataset / a data breach / a digital footprint
- compatible with / dependent on / vulnerable to

# Situaciones de uso

1. **Describir:** The model detects unusual activity.
2. **Explicar:** The recommendation system is trained on user data.
3. **Advertir:** The dataset may contain historical bias.
4. **Proteger:** The service encrypts messages end to end.
5. **Solucionar:** Restart the router and troubleshoot the connection.
6. **Evaluar:** The tool is useful, but its results still require human review.

# Explicación

Un **algorithm** es un conjunto de instrucciones; un sistema de **machine learning** aprende patrones a partir de ejemplos. El conjunto de ejemplos se llama **dataset** y el resultado puede depender de la calidad de esos datos. Un **chatbot** conversa con usuarios, mientras que una **user interface** permite manejar una aplicación.

En el uso responsable conviene hablar de **privacy**, **encryption**, **consent** y **bias**. Una herramienta puede ser eficiente y, a la vez, producir resultados sesgados si el dataset no representa a todas las personas. Un **data breach** expone información sin autorización; una **digital footprint** es el rastro que dejamos al usar servicios en línea.

# Palabras que se confunden

## Algorithm, model y dataset

El algorithm contiene las instrucciones; el model es el sistema entrenado para producir resultados; el dataset son los datos usados para entrenarlo o evaluarlo.

## Privacy y security

Privacy trata de quién puede recoger o usar información personal. Security trata de proteger sistemas y datos frente a accesos o daños. Una aplicación puede tener buena seguridad técnica y, aun así, pedir más datos personales de los necesarios.

## Bias y error

Un error es una respuesta incorrecta concreta. Bias es un patrón sistemático que favorece o perjudica a un grupo. Por eso no basta con comprobar un solo resultado.

# Ejemplos

1. **The algorithm flags unusual payments for human review.**
2. **The model was trained on a dataset collected from hospitals.**
3. **The company obtained consent before analysing location data.**
4. **Encryption protects the contents of the message.**
5. **The update fixed a security vulnerability.**
6. **A biased dataset can produce unfair recommendations.**
7. **I had to troubleshoot the printer before joining the meeting.**

# Errores frecuentes

- ❌ The app learns by an algorithm.
- ✅ The app uses an algorithm.
- ❌ We must protect the private of users.
- ✅ We must protect users' privacy.
- ❌ The model has a biased result.
- ✅ The model produces a biased result.
- ❌ I updated the patch.
- ✅ I installed the patch / updated the software.
- ❌ The file is compatible to my phone.
- ✅ The file is compatible with my phone.

# Variación de uso

- **Data** puede usarse como incontable en muchos contextos actuales: *The data is stored securely*.
- **AI** suele ser incontable: *AI is changing the industry*.
- **Software** no tiene plural regular; para hablar de elementos concretos se usa *software tools* o *programs*.

# Para recordar

- Algorithms process instructions; models learn patterns from datasets.
- Privacy, consent, encryption y security describen dimensiones distintas.
- Bias es un patrón sistemático, no solo un error aislado.
- Update software, install a patch y troubleshoot a problem son colocaciones útiles.

# Comprueba lo aprendido

1. The model was trained on a large ___. (dataset)
   - Respuesta: dataset
   - Explicación: A dataset es un conjunto organizado de datos.
2. The company asked for users' ___. (consent)
   - Respuesta: consent
   - Explicación: Consent es el permiso informado.
3. The messages are protected by ___. (encryption)
   - Respuesta: encryption
   - Explicación: Encryption convierte los datos en una forma protegida.
4. The application is compatible ___ older phones. (with)
   - Respuesta: with
   - Explicación: Compatible lleva la preposición with.
5. We need to ___ the network before the presentation. (troubleshoot)
   - Respuesta: troubleshoot
   - Explicación: Troubleshoot significa investigar y resolver un problema técnico.
