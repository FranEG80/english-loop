# Resumen

Las comparaciones B2 permiten expresar proporción, semejanza, hipótesis y diferencias graduales. No basta con elegir entre dos adjetivos: hay que decidir si comparamos dos entidades, describimos un cambio paralelo o presentamos una apariencia. Las estructuras the more...the more, as...as, like, as if y as though tienen funciones distintas.

# Objetivos

- Relacionar dos cambios con the more...the more y the less...the less.
- Usar as...as, not so...as y formas intensificadas como nowhere near as.
- Distinguir like + nombre de as + cláusula o función.
- Elegir as if y as though según una apariencia real o hipotética.

# Forma o estructura

- the + comparativo, the + comparativo: The more you practise, the more fluent you become.
- the less + nombre o verbo, the fewer/less + resultado: The less waste we produce, the lower the cost.
- as + adjetivo/adverbio + as: as clear as, as quickly as.
- not as/so + adjetivo/adverbio + as: not so clear as.
- nowhere near/almost/nearly + as...as: grado de diferencia o aproximación.
- like + nombre/pronombre: It looks like rain.
- as + cláusula o función: As we discussed; as a researcher.
- as if/as though + cláusula: She behaves as though she owned the place.

# Usos principales

1. **Cambios proporcionales:** The more data we collect, the more confident the forecast becomes.
2. **Igualdad:** This model is as efficient as the previous one.
3. **Diferencia graduada:** The replacement is nowhere near as noisy as the old motor.
4. **Semejanza:** The new sculpture looks like a folded sail.
5. **Función o papel:** As the duty manager, Priya handles late arrivals.
6. **Apariencia:** The child looks as if she has heard surprising news.

# Explicación

En The more carefully we plan, the fewer delays we have, la primera parte expresa una variable y la segunda muestra el cambio relacionado. Ambas partes llevan comparativo y artículo the; no se trata de un superlativo.

Para igualdad usamos as + adjetivo o adverbio + as: The second route is as reliable as the first. Para desigualdad usamos not as/so...as: The second route is not as reliable as the first. Nowhere near as y almost as permiten graduar la diferencia.

Like funciona normalmente como preposición ante un nombre o pronombre: She sings like her mother. As introduce una cláusula o una función: As the project coordinator, he approves the timetable; As I expected, the train was late. As if y as though introducen una apariencia: He talks as if he knew the answer.

# Contrastes importantes

## Like frente a as

Like va delante de un nombre: He works like a consultant. As puede introducir una cláusula: He works as the consultant advised. También usamos as para indicar función: She joined the panel as an observer. En el habla informal se oye like con cláusulas, pero en escritura cuidada conviene distinguir los patrones.

## As if frente a una afirmación factual

He looks as if he is tired presenta una apariencia compatible con un hecho real. He talks as if he were the director puede presentar una situación hipotética o una crítica. El pasado en la segunda parte no siempre habla de tiempo pasado: puede marcar distancia o irrealidad.

## Fewer frente a less

Fewer acompaña nombres contables plurales: fewer complaints, fewer meetings. Less acompaña nombres incontables: less traffic, less equipment. En la estructura correlativa, el sustantivo determina la elección.

# Ejemplos

1. **The more clearly we define the task, the faster the team works.** — Cuanto más claramente definimos la tarea, más rápido trabaja el equipo.
2. **The less traffic there is, the quieter the neighbourhood becomes.**
3. **This route is almost as scenic as the coastal road.**
4. **The new battery is nowhere near as heavy as the old one.**
5. **The child looks like her grandmother.**
6. **As the project lead, Omar signs the final plan.**
7. **She speaks as if she had attended the meeting.**
8. **He behaves as though he owned the whole building.**

# Errores frecuentes

- ❌ The more we practise, more confident we become.  
  ✅ The more we practise, the more confident we become.
- ❌ The device is as reliable than its predecessor.  
  ✅ The device is as reliable as its predecessor.
- ❌ She works like a laboratory manager advises.  
  ✅ She works as the laboratory manager advises.
- ❌ There are less complaints this month.  
  ✅ There are fewer complaints this month.
- ❌ He looks as a professional athlete.  
  ✅ He looks like a professional athlete.

# Excepciones relevantes

- En contextos informales, like puede aparecer delante de una cláusula, especialmente en conversación.
- En un texto académico o profesional, as o as if suele hacer más clara la relación.
- Algunas expresiones lexicalizadas, como as well as y as soon as, no son comparaciones libres y deben aprenderse como unidades.
- En as if y as though, el indicativo y el pasado pueden alternar según la perspectiva del hablante.
- El pasado puede expresar distancia, no necesariamente anterioridad.
- La forma debe elegirse junto con el significado que se quiere transmitir.

# Mini resumen

- The more...the more relaciona dos cambios paralelos.
- As...as expresa igualdad; not as...as expresa desigualdad.
- Like introduce nombres; as introduce cláusulas o funciones.
- As if y as though presentan una apariencia.
- Fewer acompaña contables; less acompaña incontables.

# Comprobación rápida autocorregible

1. The ___ we practise, the more natural the rhythm becomes. (more)
   - Respuesta: more
   - Explicación: La estructura correlativa usa the + comparativo en ambas partes.
2. The machine is as quiet ___ the new model. (as)
   - Respuesta: as
   - Explicación: La igualdad se forma con as...as.
3. The report contains ___ errors than the draft. (fewer)
   - Respuesta: fewer
   - Explicación: Errors es un nombre contable plural.
4. She looks ___ her sister. (like)
   - Respuesta: like
   - Explicación: Like precede a un nombre o pronombre.
5. He speaks as ___ he knew the answer. (if)
   - Respuesta: if
   - Explicación: As if introduce una apariencia o hipótesis.
